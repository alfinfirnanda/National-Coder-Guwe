Inspirasi Proyek

Cara terbaik memahami konsep coding adalah dengan langsung membangun proyek nyata. Kamu juga bisa langsung mencoba menjalankan kode programnya di bawah ini!

1. Java — Orientasi Objek & Logika Terstruktur

Proyek Java sangat cocok untuk melatih pemahaman struktur data, logika transaksi, serta paradigma Object-Oriented Programming (OOP)

Aplikasi Kasir CLI

Melatih logika kondisi, kalkulasi total belanja, dan perhitungan kembalian lewat terminal

Manajemen To-Do List

Belajar menyimpan, membaca, dan menghapus daftar tugas berbasis File I/O

Game Tebak Angka

Mengasah logika perulangan (while) dan penggunaan library acak (Random)

Contoh Program: Kasir Sederhana 
public class Main {
    public static void main(String[] args) {
        System.out.println(" PROGRAM KASIR SIMULASI ");
        int totalBelanja = 50000;
        int uangDibayar = 100000;
        int kembalian = uangDibayar - totalBelanja;
        
        System.out.println("Total Belanja : Rp " + totalBelanja);
        System.out.println("Uang Dibayar  : Rp " + uangDibayar);
        System.out.println("Kembalian     : Rp " + kembalian);
    }
}

2. JavaScript — Interaktivitas Web & DOM

Kalkulator Web

Task Tracker

Menambah, menandai selesai, dan menyimpan data di LocalStorage browser.

Dark Mode Switcher

Ubah skema warna seluruh halaman secara instan dengan manipulasi class CSS.

console.log("--- SIMULASI TEMA WEB ---");

if (isDarkMode) {
    console.log("Status: Dark Mode Aktif (Latar belakang gelap)");
} else {
    console.log("Status: Light Mode Aktif (Latar belakang terang)");

3. C++ — Performa & Manajemen Memori

Melatih ketelitian logika dasar, penggunaan array, serta pemrosesan algoritma yang cepat dan efisien

Game Tic-Tac-Toe

Memahami konsep Array 2 Dimensi dan pengondisian giliran pemain

Konverter Suhu

Program perhitungan rumus matematika konversi Celcius, Fahrenheit, dan Kelvin

Simulasi Antrian Bank

Menerapkan konsep struktur data Queue (First-In, First-Out)

Contoh Program: Konversi Suhu 
#include <iostream>
using namespace std;

int main() {
    float celcius = 30.0;
    float fahrenheit = (celcius * 9.0 / 5.0) + 32;

    cout << "--- KONVERSI SUHU ---" << endl;
    cout << "Suhu Celcius   : " << celcius << " C" << endl;
    cout << "Suhu Fahrenheit: " << fahrenheit << " F" << endl;

    return 0;
}
