Common Error Database

Kumpulan pesan error yang paling sering ditemui pemula, lengkap dengan solusinya.

404 Not Found

Artinya: File yang diminta tidak ditemukan di server.

Cara mengatasinya:

  • Cek kembali nama file
  • Cek path / lokasi file
  • Pastikan file ada di dalam folder yang benar
SyntaxError: Unexpected token

Artinya: Ada penulisan kode yang tidak sesuai aturan bahasa pemrograman.

Cara mengatasinya:

  • Cek tanda kurung, kutip, dan titik koma yang mungkin belum ditutup
  • Perhatikan baris dan kolom yang ditunjukkan pada pesan error
  • Bandingkan dengan contoh kode yang sudah benar
NullPointerException

Artinya: Program mencoba mengakses objek yang belum diberi nilai (masih null).

Cara mengatasinya:

  • Pastikan variabel sudah diinisialisasi sebelum dipakai
  • Tambahkan pengecekan kondisi if (variabel != null)
  • Lacak baris yang disebutkan pada stack trace error

Common Problems & Solutions

Problems that are frequently experienced by beginner programmers.

Problem
Many beginners panic when they see an error message.


Solution
Read the error carefully, identify the line number, then search for the meaning before changing your code.

Problem
Too many programming languages make beginners confused.


Solution
Start with HTML, CSS, JavaScript, then continue to Python or Java.

Problem
Many beginners don't know what project to build.


Solution
Try making a calculator, to-do list, weather app, or portfolio website.

Problem
Feeling like your coding skills never improve.


Solution
Build one small project every week instead of aiming for a huge application.
